# Overview

Clauding is a command-line launcher for an existing [Claude Code](https://code.claude.com/docs/en/setup) installation. It reads a user-selected Messages API endpoint, model ID, optional context window, and launcher-specific MCP configuration. A local LM Studio server is one supported endpoint shape.

The npm package ships the launcher and this documentation. Claude Code, the inference server, and MCP servers are installed separately and carry their respective terms.
